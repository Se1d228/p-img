# P-IMG project
This is programmable images project
-----------------------------------------------
## Usage:
Flags:
-c; --cli - render image in console
-f; --filename - filename
Example:
```sh
python3 p-img.py -f "example.pimg"
```
-----------------------------------------------
Installation:
```sh
git clone https://github.com/Se1d228/p-img
```
